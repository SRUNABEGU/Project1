## Приложение для анализа банковских транзакций
### Описание
Приложение для анализа транзакций, импортируемых из Excel-файла,\
генерирации JSON-данных для веб-страниц, формирования отчетов.
### Функции
**Анализ банковских карт**: Просмотр общей суммы расходов и кэшбэка по картам\
**Топ транзакций**: 5 самых крупных операций\
**Курсы валют**: Актуальные курсы USD и EUR к RUB\
**Цены акций**: Стоимость акций компаний из S&P500\
**Поиск операций**: Поиск по категориям и описаниям\
**Excel отчёты**: Генерация отчётов по категориям в формате Excel
